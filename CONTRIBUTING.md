# Contributing to Project VERDANT

We welcome contributions to Project VERDANT. This project is built as an open-source tool for municipal document intelligence and cadastral reconciliation.

## Code of Conduct

Contributors are expected to adhere to standard professional conduct: treat all participants with respect, provide constructive feedback, and prioritize open, reproducible engineering.

## Development Workflow

1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/my-feature
   ```
2. Set up the development environment using Python 3.10+ and Docker.
3. Ensure all tests and linting pass before submitting:
   ```bash
   pytest tests/
   ```
4. Submit a Pull Request targeting `main`.

## Security Disclosures

If you discover a security vulnerability or PII handling issue, please open a private security advisory on GitHub or contact the maintainers directly.
